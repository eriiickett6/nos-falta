# Nos Falta

Lista de la compra compartida para pisos y familias. Proyecto de emprendeduría (iFest · FP Empren) de Aleix, Marc y Eric.

- Catálogo de productos y precios reales de supermercados en Supabase.
- Casa compartida con código: lista, turno de compra y reparto de gastos.

## Fuentes de datos
- Productos y fotos: [Open Food Facts](https://world.openfoodfacts.org) (ODbL, fotos CC BY-SA).
- Precios: [Open Prices](https://prices.openfoodfacts.org) (ODbL), webs de los supermercados y precios apuntados a mano.
- Fotos de fruta y verdura: [Fruits-360](https://github.com/fruits-360/fruits-360-100x100), Mihai Oltean (CC BY-SA 4.0).
